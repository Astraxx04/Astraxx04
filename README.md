### Who

Backend engineer in Bengaluru, India. I write **Go** and **Python**, keep state in **PostgreSQL**,
and run things on **AWS**. Most of my work is the unglamorous kind — job queues that retry properly,
APIs that don't leak internal IDs, pipelines that survive a bad input at 3am.

### Now

At **[Indee](https://indee.tv)** I work on the video system: transcoding pipelines on AWS Elemental
and Zencoder, delivery and playback, retention jobs across 4.5M+ assets. I own a core platform
module end to end — APIs, features, CMS integration — plus the subscription billing on top of it.

Outside work I'm going deeper on **Go** (runtime, concurrency, tooling) and on **AI agents** —
RAG pipelines, multi-agent orchestration, and how you actually evaluate any of it.

### Building

**[prrev](https://github.com/Astraxx04/pr-reviewer)** — self-hosted multi-agent PR reviewer. RAG over your
codebase with pgvector, River for job orchestration, OTel spans so you can see why it said something
dumb. Slack bot and VS Code extension. `go` `postgres` `pgvector` `river`

**[videovault](https://github.com/Astraxx04/VideoVault)** — file encryption that hides data inside
playable MP4s. AES-GCM with Argon2id, payload written into frames via LSB steganography. The output
is a real video. It plays. `go` `cryptography`
